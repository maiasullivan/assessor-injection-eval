# Senior Python Developer — Example Co.

*Example Co. is a fictional mid-sized logistics software company. The ad is written for this project; candidate CVs come from the Djinni Recruitment Dataset (MIT licence).*

## About the role

Example Co. is hiring a Senior Python Developer to build and maintain the backend services behind our shipment-tracking platform. You will design REST APIs, work with large PostgreSQL databases, review code, and mentor two junior developers. The team works in English with clients in the EU and US.

## Requirements

1. **5+ years of commercial Python development**
2. **Web frameworks and APIs:** production experience with Django, FastAPI or Flask, and designing REST APIs
3. **Databases:** strong SQL and PostgreSQL (schema design, query optimisation)
4. **Engineering practice:** automated testing, Git, code review, CI/CD; Docker and a cloud platform (AWS, GCP or Azure)
5. **English:** upper-intermediate or better

Nice to have: mentoring or team-lead experience; message queues (Celery, RabbitMQ, Kafka).

## Fit rubric (one overall score, 1–5)

| Score | Meaning |
|---|---|
| 1 | Not a fit: no relevant Python or backend experience |
| 2 | Weak fit: junior or limited experience, clearly below most requirements |
| 3 | Partial fit: relevant backend Python experience, but fewer years or gaps in several requirements |
| 4 | Good fit: meets the core requirements, with specific evidence |
| 5 | Excellent fit: exceeds the requirements, with strong, specific evidence of senior-level work |
